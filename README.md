# dotsnap

AI生成のピクセルイラスト・スプライトシートを、指定サイズと色数のドット絵に整えるブラウザツール。元画像の色と形を参照した自動補修を備えています。

## 開く

- **すぐ使う:** `dotsnap-standalone.html` をブラウザで開く。この1ファイルだけで使えます。
- **開発用:** `dotsnap.html` を開く。同じフォルダのCSS・JavaScriptが必要です。
- **ローカルプレビュー:** Node.jsで `npm start` を実行し、http://127.0.0.1:4173 を開く。

依存パッケージのインストール・アカウント・APIキーは不要です。画像処理と作業ファイルの読み込みはブラウザ内で完結し、フォントを含め外部サービスへのリクエストはありません。

## 使い方

左カラムの「dotsnap」タイトル右側の「？」アイコンから、ヘルプ・マニュアルを開けます。基本操作、変換設定、手仕上げ、保存・書き出し、キー操作、困ったときの対処を収録しています。「閉じる」またはEscで編集画面に戻れます。

1. 画像を開く、ドロップする、またはCtrl+Vで貼り付ける。「デモ画像で試す」も利用できます。
2. コマサイズと最大色数を指定する。まず「全体を収める」「自動補修ON」「おまかせ」を試してください。
3. 単体イラストは「一枚のイラスト」、シートは自動分割または列・行を指定する。
4. 3候補、補修前／後、補修箇所の重ね表示、アニメーションで確認する。
5. シートPNG、選択コマPNG、全コマZIP、コマ情報JSONで書き出す。
6. 「作業を保存」で画像・設定・コマ範囲・位置補正を `.dotsnap` ファイルへ保存。「再開」で読み戻せます。

## 自動補修

生成AIや画像認識モデルは使用していません。次の決定的な画像処理を行います。

1. 透明情報、外周につながる近似色、または指定キー色から背景を除去。
2. コマを分割し、エッジの間隔からドットピッチを推定。
3. 出力枠への配置と共通倍率を決定。元の相対位置を保持する配置では、ジャンプなどの移動量を残す。
4. 各出力セルについて、元画像の不透明部分の割合と色の分布を調べる。
5. 多数決のサンプリングで消えた細線を、元画像に不透明部分があり周囲との接続を支持できる場合に補完。
6. 小面積でもコントラストの強い色が近傍から消えた場合、色を補う候補を作る。
7. 全コマ共通のパレットで減色。自動補修ON時は少数色の重みを上げる。
8. 「原画に忠実」「細部をくっきり」「すっきり整理」の候補を、元画像との輪郭・色・アクセント色の整合性で比較する。

「すっきり整理」は保守的な補修方針です。孤立ドットを無差別に削除する機能ではありません。

「補修する範囲」で **縁だけ / 全体（縁＋内側）** を選べます。初期値は全体です。
- 縁だけ：補修前の透明／不透明の境界に接する1ドットを対象にします。内側の透明な穴の縁も含みます。内部の画素は補修せず、パレットも補修前から作ります。
- 全体：縁に加え、内側のアクセント色の復元と、色領域の小さな欠け・突起の補修を行います。周囲3方向以上で支持され、元画像の同じセルにもその色が残っている場合だけ色を置き換えます。原画にない色や形を推測して描き足しません。

この範囲指定は自動補修の対象です。通常の減色・縁線追加は別に適用されます。補修OFFではどちらの範囲も補修しません。範囲の選択は作業保存・元に戻すにも含まれます。

補修前／後は、**同じパレットと縁線設定**で比較し、細線・アクセント色の補修の差を表示します。補修箇所は赤系の重ね表示で、書き出すPNGには含まれません。自動補修OFFでは少数色への重み付けも解除します。

## サイズ・色数の扱い

- コマサイズは幅・高さそれぞれ8〜512px。
- 自動パレットは透明を除く最大2〜256色。縁線色・保護色もこの上限に含めます。
- 固定パレット指定時は、そのパレットのみを使います。最大色数の入力より固定パレットを優先し、縁線もパレット内の色へ合わせます。
- 透明度は0または255。アンチエイリアス付きの半透明画素は出力しません。
- 「全体を収める」は必要に応じて共通倍率を調整します。コマの位置補正を行った場合は、はみ出しが起こり得るため表示で通知します。
- 抜き色の許容範囲・色かぶり除去を変更しても、コマ分割・倍率・配置は変わりません。色抜きモードでは、幾何解析専用の一定条件（許容範囲80・色かぶり除去ON）で分割・格子・絵の範囲を推定し、描画時だけ指定した許容範囲を使います。許容範囲が低すぎる場合は背景が残りますが、その残りを理由に絵を縮小し直しません。キー色・背景モード・分割設定・サイズの変更時は再解析します。
- 「密度を維持して切り出す」は推定ピッチを優先し、はみ出す部分を切り取ります。
- 入力は1600万画素まで。出力は合計800万画素・シートの一辺16384pxまで。
- 出力PNGはRGBA形式です。使用色数を制限しますが、インデックスカラーPNGではありません。

## その他の操作

- 左右カラムのスクロール: デスクトップ幅では、左の設定と右の結果一覧がそれぞれ独立してスクロールします。左の下部設定を操作しても右の結果位置は変わりません。
- 補修前／後の比較: 同じ大きさの2つの表示枠で比較します。どちらの枠をスクロール・画像ドラッグしても縦横の位置が連動し、倍率と格子表示も共通です。設定の再計算でも表示位置を維持します。スマートフォン幅では2つの比較枠を上下に並べます。

- 背景のスポイト: 「元画像から選ぶ」を押して元画像をクリック。
- 抜き色: 色を変更すると「指定色を全体から抜く」に切り替わり、囲まれた部分も透明になります。表示中の色をそのまま使う場合は「この色を全体から抜く」を押してください。
- 暗い抜き色・縁の色かぶりを除去（初期ON）: 彩度の高い抜き色では、暗い同系色も背景判定します。透明部分の近くに混ざった抜き色は色成分を抑え、輪郭の透明度は維持します。緑の衣装など必要な同系色も対象になる場合があるため、OFFで従来のRGB距離判定に戻せます。「元の透明を使う」「色による除去なし」では適用しません。
- 手動コマ分割: 「範囲を手動指定」を選び、元画像上をドラッグして順に追加。やり直しは「戻す」、全消去は「範囲をクリア」。
- 保護色: パレットの色をクリックすると保護／解除。保護はパレットへの収録を保証するもので、特定の場所に描くことを保証するものではありません。
- 位置補正: コマを選び、横・縦を出力ドット単位で指定。正の値はサンプリング領域を右／下へ動かすため、絵は左／上へ動きます。
- アニメーション: 全コマまたは行を選び、1〜30fpsで再生。前のコマを薄く重ねて確認できます。
- Ctrl+Z / Ctrl+Shift+Z: 設定・範囲・位置補正を戻す／やり直す。

## 現時点の限界

顔の意味を理解して目を描き直す、異なるコマの顔を認識して同じ顔に修正する、といった意味理解による補修は未実装です。格子が大きく歪んだ画像や、極端な低解像度化では形が変わることがあります。コマ間の統一は共通倍率・配置・格子位相・パレットによるもので、動きの推定による修復は行いません。

自動候補の選択は画像特徴による評価であり、美的品質や完全復元の保証ではありません。実際のAI生成画像を使った幅広い品質評価は今後の課題です。手仕上げのペン・消しゴムを搭載しています。元画像への背景マスクブラシは含めていません。

## 開発

```text
npm start       ローカルプレビュー
npm test        処理・ZIPのテスト
npm run build   単一HTML版を再生成
```

- `engine.js`: 元の実装から引き継いだピッチ推定と減色の基本処理。
- `processor.js`: 背景、分割、配置、補修、候補評価、パレット管理。
- `app.js`: UI、Web Worker、履歴、アニメーション、入出力。
- `zip.js`: 外部依存のないZIP出力。
- `styles.css`: レスポンシブUI。
- `dotsnap-original.html`: 改修前の版をそのまま保存したもの。この旧版には外部フォント参照があります。

処理はWeb Workerで実行し、設定が変わったら古い処理を中断します。Workerを作成できない環境ではメインスレッドで実行します。

## 検証

自動テストでは出力サイズ、半透明の排除、縁線込みの色数、固定パレット、背景の連結判定、元の透明情報、細線補完、小さなアクセント色の自動復元、補修OFF、ジャンプ位置、入力検証、処理の再現性、Workerでの実行、手動範囲、ZIP構造・CRCを検証しています。

ブラウザでもデモ画像の変換・比較・補修OFF・履歴・再生・保存と読み戻し・PNG／ZIP出力を確認。実際の書き出しファイルを独立したPNGデコーダーで読み、16×16pxの8コマ、4色以内、透明度0/255を確認しています。


## 手仕上げ（変換結果を確定して編集）

「確定して手仕上げへ」で注意書きを確認すると、選択した候補を確定して編集モードへ切り替えます。変換設定はロックされ、コマの幅・高さは固定です。

- コマを選び、共通パレットの色でペン描画・描き足し、消しゴムで透明化、スポイトで色選択できます。ドラッグ1回をまとめて戻せます。
- 矢印ボタンまたは矢印キーで絵全体を1ドット移動します。枠外の画素も保持するため、逆方向へ移動すれば復元できます。出力は枠内だけです。
- 「確定時 / 手仕上げ」で比較。「手修正を反映」は表示だけの切替で、PNG・ZIP・アニメーションは常に手修正後です。
- 「このコマの修正をリセット」で確定時へ戻します。この操作も戻せます。
- 「作業を保存」は確定画像・パレット・枠外を含む編集内容を保存します。再開すると手仕上げモードに戻ります。操作履歴は再開時には引き継ぎません。従来の作業ファイルも読み込めます。
- 変換設定へ戻る際は、手仕上げの破棄を確認します。残したい場合は先に保存してください。

補修箇所は白黒のマークで強調し、「点滅」でゆっくり切り替えられます。手仕上げ中は格子・補修箇所・点滅の操作を非表示にし、「確定時 / 手仕上げ」で比較します。表示マークや格子は出力画像に含めません。

プレビュー下端をドラッグ（フォーカス後の上下キーでも可）すると高さを変更できます。「プレビューを最大化」で画面いっぱいに広げ、同じボタンまたはEscで戻れます。最大化中も手仕上げのコマ選択・戻す・保存が使えます。

背景の許容範囲は0〜442です。442では全色が判定対象になるため、必要な部分も抜けます。「抜く色をスポイトで追加」で元画像から最大32色を追加でき、追加色をクリックすると解除できます。追加時は「指定色を全体から抜く」へ切り替わり、同じ許容範囲で判定します。追加色は色抜きにだけ使い、コマ分割・倍率・配置の解析には使いません。暗い同系色や縁の色かぶり補正は主指定色を基準にします。

`manual.js` は手仕上げの画素・移動・履歴・保存を管理します。`tests/manual-browser.cjs` はPlaywrightとEdgeを使う任意の画面テストです（別途 `npm start` が必要）。

ヘッダーにあった画像読み込み・保存・履歴・出力は左カラムへ集約しました。手仕上げ中は左の変換設定をツールとパレットに置き換え、右のキャンバスを高く表示します。最大化中も左のツールを使えます。元画像表示では適用されない格子・補修箇所・点滅・倍率操作を非表示にします。

手仕上げの道具はラジオボタンで選びます。ペン中はShift＋クリック／ドラッグで一時消去、Alt＋クリックで色を取得できます。ラジオの選択は変わりません。両方を押した場合はAltのスポイトを優先します。手仕上げの左にある「ドット格子」は全倍率で1ドット単位の境界を表示します。変換プレビューの格子も表示解像度の1px線で描画し、PNGには含めません。

変換プレビューの格子は「コマ枠」（出力コマの幅・高さごとの境界）と「ドット格子」（1ドットごとの境界）に分離しました。それぞれ独立してON/OFFでき、同時表示も可能です。倍率では種類を切り替えません。手仕上げは単独コマ表示のため「ドット格子」のみです。

手仕上げの最大倍率は6400％です。＋（＝）/ −で倍率を一段ずつ切り替え、Ctrl＋ホイールでも拡縮できます。カーソル横に現在の道具（ペン・消しゴム・スポイト）を表示し、Shift/Altでの一時切替も反映します。ツール欄の「戻す／やり直す」に加え、Ctrl+Z、Ctrl+Shift+ZまたはCtrl+Yで履歴操作できます。MacではCtrlの代わりにCommandを使えます。文字や数値の入力中は入力欄の通常操作を優先します。
